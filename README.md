
# 🇧🇷 ZYNEX BOT — EB DO PRO

Bem-vindo ao repositório oficial do ZYNEX BOT!

## 🤖 Sobre o projeto

O ZYNEX BOT é um bot desenvolvido para o servidor EB DO PRO, com comandos e ferramentas de administração para a comunidade.

## ⚙️ Arquivos do projeto

- `index.js` — Código principal do bot.
- `package.json` — Configurações e dependências.
- `.github/workflows/blank.yml` — Configuração de execução do projeto.

## 🛠️ Tecnologia

- Node.js
- Discord.js v14

## 🔒 Segurança

Nunca compartilhe o token do bot.
As credenciais devem ser armazenadas como segredos do repositório.
